板载按键

BANK_3 = 1.5V，按下为低
SW1
零位标定把摆杆扶到你想要的竖直零位，按住 ≥20 ms 后松开。锁存当前 ADC 为绝对零位；复位/重新烧录后失效。
SW2
短按：轨迹模式（6 档）0° → +45° → −45° → +90° → −90° → 0.1 Hz 正弦，循环。长按 ≥0.7 s：只清 PID 慢积分不动编码器、不动基准线。（换零/锚定请用 SW4 长按）
SW3
电机使能翻转上电默认关闭（安全）。按一次开，再按一次关；起摆/平衡都需要它为开。
SW4
短按：停机刹车 / 自由滑行切换0 = 自由滑行，1 = 动态能耗制动。只在电机使能关闭后有意义。长按 >0.7 s：转臂基准清零把当前转臂位置锚成 α=0，同时触发 pos_traj_gen.rezero。换零、A/B 实验用这个。
SW5
异步复位清状态机、清标定、电机回到关闭、轨迹模式回 0。相当于重新上电。
上电 SOP：扶正摆杆 → 短按 SW1 标定 → 短按 SW3 使能电机 → 自动起摆。烧录前务必扶稳摆杆并确认 SW3 为关。

θ/α 都用去均值标准差 σ；窗口是“最长一段 BALANCE，跳过前 2 s”，与文档里固定 30–80 s 的数值不可直接比。FFT 为 2 的幂，不足 256 点（2.56 s）不报主频/音调幅；没有 BALANCE 段时统计退回全段并标注，频域留空；稳定段少于 32 点只报时长，σ/噪音/饱和留空。音调幅用锁相估计，饱和按 |duty| ≥ 1000。“起摆→首捕”= 首个 SWINGUP 起点到首个 BALANCE 入点。
