## 5. 接线

| ESP32-S3 | 方向 | FPGA（底板 GPIO 排针） |
|---|---|---|
| GPIO18 (UART1 TX) | → | 丝印 **AB11**（FPGA RX） |
| GPIO17 (GPIO 输入) | ← | 丝印 **W10**（FPGA ACK 脉冲，宽度 `(mode+1)*100 ms`） |
| GND | — | GND |

- 两侧都是 3.3V，**不要电平转换**；
- 上电前用万用表确认 AB11/W10 与核心板 J2 的 1/3 脚通断；
- Bank5 是 3.3V，**不要接到 Bank3（1.5V）**。

## 6. 测试

### 6.1 不接 K230

在 `app_main.c` 里临时调用：

```c
    fpga_link_init();
    fpga_link_selftest_start();
```

烧录后 ESP32 每 3 秒依次发 0 / +90 / −90 / 0 档，日志：

```text
FPGA_LINK: selftest -> mode 3
```

用 USB-TTL 或逻辑分析仪量 FPGA RX（AB11），应看到：

```text
AA 55 01 03 58
```

（`58 = 0x01 ^ 0x03 ^ 0x5A`）

### 6.2 接 K230

K230 手势脚本里把 `ENABLE_TCP = True`，ESP32 日志会打印：

```text
FPGA_LINK: gesture left -> mode 4
```

FPGA 侧按 `fpga_cmd/INTEGRATION.md` 集成后，串口遥测/转臂动作应随档位变化。

---

## 7. 注意

1. **不要再调用 `uart_startup()`**：它也用 UART1（GPIO17/18），会和本模块抢串口。
2. 心跳每 500 ms 一帧；FPGA 侧 `link_alive` 可用于指示链路状态，但**失联不改变当前档位**，不会让倒立摆突然停。
3. 手势只改目标档位，**不使能电机**；电机使能仍由 SW3 控制。
4. 映射在 `fpga_link.h` 顶部：

```c
#define FPGA_MODE_STOP   0
#define FPGA_MODE_RIGHT  3   // +90°
#define FPGA_MODE_LEFT   4   // -90°
```

要改成 ±45° 或连续旋转，只改这里（FPGA 侧需有对应档位）。
